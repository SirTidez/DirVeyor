# FileAdmin

FileAdmin is a planned Rust terminal application for fast, understandable file
management. It combines a keyboard-first two-pane browser with an explicit
operation queue, device-aware transfer planning, and safety-focused previews.

This repository is currently in the concept and requirements phase.

## Design documents

- [Product requirements](docs/PRODUCT_REQUIREMENTS.md)
- [Interface concepts](docs/INTERFACE_CONCEPTS.md)

## Current phase

1. Validate the interaction model and visual hierarchy.
2. Turn the requirements into an architecture decision record.
3. Scaffold the Rust workspace and build a read-only browsing prototype.
